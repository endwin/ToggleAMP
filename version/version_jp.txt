# [v1.3.0] - 2026-09-06
- [ブランド] プロジェクトおよびプログラム公式名称を「ToggleAMP」へ変更・リブランディング
- [インストーラー/Setup] オールインワン単一実行インストーラー ToggleAMP-setup-v1.3.0.exe および uninstall.exe 構築 (パス選択、ショートカット、レジストリ登録)
- [データベース] MariaDB(11.4 LTS, 10.11 LTS) および MySQL(8.4 LTS, 8.0, 5.1 Legacy) 専用の軽量・最適化
- [安全性] PHP 5.2.9 および MySQL 5.1.33 必須レガシー基本パッケージの削除防止ロック(Protected Lock) 適用
- [デスクトップ/C#] ネイティブ C# システムトレイ(System Tray) & 統合コントロールセンター ToggleAMP.exe 構築
- [デスクトップ/UI] 直感的なヘッダー配置、アクティブスタックバッジ、5つのサービス(Web/PHP/DB/Redis/Mailpit) リアルタイムポート＆稼働状態追跡
- [デスクトップ/操作] サービス稼働状態に応じた [ 開始 ] ↔ [ 終了 ] 動的トグルボタン & 下部大型リアルタイム活動ログコンソール
- [デスクトップ/トレイ] チラつきや位置飛びのない安定したトレイサブメニュー & bin/にインストールされたパッケージのみ正確にフィルタリング表示
- [デスクトップ/ツール] トレイのWebツールにデュアル phpMyAdmin(最新 v5.2 / 3.1 レガシー) 搭載 & アクティブなPHPバージョン(PHP 5.2 ↔ PHP 7〜8)に応じたリアルタイム有効化/無効化連携
- [デスクトップ/同期] サーバーでのパッケージ(PHP/DB)追加・削除時にシステムトレイおよびコントロールセンターへリアルタイム自動反映
- [デスクトップ/アイコン] ToggleAMP マルチ解像度 Windows .ico 生成および ToggleAMP.exe、トレイ、ショートカット、ウィンドウヘッダーへ一括適用
- [多言語/i18n] システムトレイ右クリックメニューおよびデスクトップウィンドウ全体のリアルタイム3言語(日本語、韓国語、英語) 1クリック切替
- [機能/仮想ホスト] 仮想ホスト(*.test)およびプロジェクトのワンクリック完全削除機能 & defaultルートフォルダ保護
- [修正/Redis] Redis 5.0.14.1 Windows バイナリ内蔵およびサービススーパーバイザー(開始/停止/再起動) 連携
- [終了機構] デスクトップウィンドウ、トレイ右クリックメニュー、ToggleAMP-stop.cmd、CLIによる安定した独立終了 (Webダッシュボードの終了ボタン削除)
- [システム] VERSION.txt マスター単一ソース基準の多言語バージョン管理と整合性自動検証体系の確立
