# [v1.3.0] - 2026-09-06
- [브랜드] 프로젝트 및 프로그램 공식 명칭 'ToggleAMP'로 변경 및 리브랜딩
- [인스톨러/Setup] 올인원 단일 실행 설치 파일 ToggleAMP-setup-v1.3.0.exe 및 uninstall.exe 구축 (경로 선택, 바로가기 생성, 제어판 등록)
- [데이터베이스] MariaDB(11.4 LTS, 10.11 LTS) 및 MySQL(8.4 LTS, 8.0, 5.1 Legacy) 전용 경량화 및 최적화
- [보호기능] PHP 5.2.9 및 MySQL 5.1.33 필수 레거시 기본 패키지 삭제 방지 보호 잠금(Protected Lock) 적용
- [데스크톱/C#] 네이티브 C# 시스템 트레이(System Tray) & 통합 제어 센터 윈도우 ToggleAMP.exe 구축
- [데스크톱/UI] 직관적인 상단 헤더, 활성 스택 배지, 5개 서비스(웹서버/PHP/DB/Redis/Mailpit) 실시간 포트 & 가동 상태 추적
- [데스크톱/제어] 서비스 상태에 따른 [ 시작 ] ↔ [ 종료 ] 동적 토글 버튼 및 하단 대형 실시간 로그 스트림 콘솔
- [데스크톱/트레이] 타이머 깜빡임 및 위치 튐 없는 안정적인 트레이 서브메뉴 & bin/에 설치된 패키지만 정확히 필터링 노출
- [데스크톱/도구] 트레이 웹 도구에 듀얼 phpMyAdmin(최신 v5.2 / 3.1 레거시) 탑재 및 활성 PHP 버전(PHP 5.2 ↔ PHP 7~8)에 따른 실시간 활성화/비활성화 연동
- [데스크톱/동기화] 서버에서 패키지(PHP/DB) 설치 및 삭제 시 시스템 트레이 및 제어 센터 실시간 자동 반영
- [데스크톱/아이콘] ToggleAMP 멀티 해상도 Windows .ico 생성 및 ToggleAMP.exe, 트레이, 바로가기, 창 헤더 일괄 적용
- [다국어/i18n] 시스템 트레이 우클릭 메뉴 및 데스크톱 창 전체 실시간 3개 국어(한국어, English, 日本語) 1-클릭 전환
- [기능/가상호스트] 가상 호스트(*.test) 및 프로젝트 원클릭 영구 삭제 기능 & default 루트 폴더 보호
- [오류수정/Redis] Redis 5.0.14.1 Windows 바이너리 내장 및 서비스 수퍼바이저(시작/정지/재시작) 연동
- [종료메커니즘] 데스크톱 제어 센터 창, 시스템 트레이 우클릭 메뉴, ToggleAMP-stop.cmd, CLI를 통한 안정적인 독립 제어 (웹 대시보드 상단 종료 버튼 제거)
- [시스템] VERSION.txt 마스터 단일 소스 기준 다국어 버전 파일 및 무결성 자동 검증 체계 확립

# [v1.2.0] - 2026-09-01
- [데이터베이스] MariaDB 11.4 LTS 및 MySQL 8.4 LTS 데이터 엔진 자동 초기화 지원
- [시스템/무결성] version 디렉터리 기반 중앙 집중식 버전 관리 및 실제 시스템 코드 버전과의 불일치 실시간 무결성 검증

# [v1.1.0] - 2026-09-01
- [다국어/i18n] 다국어 지원 시스템 구축 (.lang 언어 팩: English 기본, 한국어, 日本語)
- [안전성] 서버 가동 중 오작동 방지를 위한 런타임 스위칭 안전 잠금(Safe Lock) 적용
- [패키지] Quick Tools & 런타임 패키지 1-클릭 설치, 적용, 삭제 매니저 구현

# [v1.0.0] - 2026-08-31
- [아키텍처] 인스톨러 없이 압축 해제 즉시 사용 가능한 독립형 포터블 멀티 스택 아키텍처
- [웹서버] Nginx 1.26.1 ⇄ Apache HTTPD 2.4.68 실시간 1-클릭 전환 (통일된 FastCGI 9000번 포트)
- [PHP] PHP 5.2.9 Legacy, 7.4.33, 8.1.34, 8.2.33, 8.3.33, 8.4.25 멀티 런타임 스위칭
- [데이터베이스] MariaDB(11.4 LTS, 10.11 LTS) 및 MySQL(8.4 LTS, 8.0, 5.1.33 Legacy) 멀티 엔진 지원
